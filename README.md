# 🎬 Teleprompter สำหรับ iPad mini 6

เว็บแอป Teleprompter (เครื่องบอกบท) แบบไฟล์เดียว ใช้งานออฟไลน์ได้
ออกแบบมาเพื่อจอ iPad mini 6 โดยเฉพาะ พื้นหลังดำ ตัวอักษรขาวใหญ่

## ✨ ฟังก์ชัน

- **พื้นหลังดำ ตัวอักษรขาว** อ่านง่าย สบายตา
- **แตะหน้าจอตรงไหนก็ได้ = เริ่ม/หยุดเลื่อนข้อความ** (แตะอีกครั้งเพื่อหยุด)
- **ลากนิ้วขึ้น-ลง** เพื่อเลื่อนหาตำแหน่งเอง
- **แตะสองครั้งเร็ว ๆ** เพื่อซ่อน/แสดงแถบเครื่องมือด้านบน
- **🪞 กระจก (สลับซ้าย-ขวา)** สำหรับใช้กับกระจกเทเลพรอมป์เตอร์ (beam splitter)
- **⇅ พลิกบน-ล่าง** เผื่อกรณีติดตั้งกล้อง/กระจกแบบกลับหัว
- **ปรับความเร็ว** และ **ขนาดตัวอักษร** ได้สด ๆ ระหว่างพูด
- **เส้นบอกตำแหน่งอ่าน** (ปิด/เปิดได้)
- **คลังเก็บสคริปต์** บันทึกไว้ในเครื่อง ไม่ต้องพิมพ์ใหม่ทุกครั้ง
- **กันจอดับ** ระหว่างใช้งาน (Wake Lock)
- รองรับ **รีโมต Bluetooth / คีย์บอร์ด**: Space = เล่น/หยุด, ลูกศรขึ้น-ลง = ความเร็ว, ลูกศรซ้าย-ขวา = ขนาดตัวอักษร

## 📁 วิธีเก็บข้อความ (2 ทาง)

### ทางที่ 1 — เพิ่มในแอป (ง่ายที่สุด)
แตะ **“＋ สคริปต์ใหม่”** พิมพ์/วางบท แล้วกดบันทึก
ข้อความจะถูกเก็บไว้ในเครื่อง เปิดมาก็เลือกใช้ได้เลย ไม่ต้องแก้ใหม่

### ทางที่ 2 — วางไฟล์ในโฟลเดอร์ `scripts/`
1. นำไฟล์ `.txt` (1 ไฟล์ = 1 บท) ไปไว้ในโฟลเดอร์ `scripts/`
2. เพิ่มชื่อไฟล์ลงใน `scripts/manifest.json` เช่น
   ```json
   [
     { "title": "ชื่อที่จะแสดง", "file": "ชื่อไฟล์.txt" }
   ]
   ```
3. เปิดแอป สคริปต์จะถูกดึงเข้าคลังอัตโนมัติ
   *(ทางนี้ทำงานเมื่อเปิดผ่านเว็บเซิร์ฟเวอร์ http/https เท่านั้น — ดูหัวข้อ "วิธีเปิด" ด้านล่าง)*

> ปุ่ม **⬇ สำรองข้อมูล** ใช้บันทึกสคริปต์ทั้งหมดเป็นไฟล์ `.json` ไว้เผื่อย้ายเครื่อง
> และปุ่ม **⬆ นำเข้าไฟล์** ใช้โหลดไฟล์ `.txt` หรือ `.json` กลับเข้ามาได้

## 📲 วิธีเปิดบน iPad mini 6

**แบบง่าย (โหมดในแอปอย่างเดียว):**
ส่งไฟล์ `index.html` ไปที่ iPad แล้วเปิดด้วย Safari — ใช้คลังในแอปได้ทันที

**แบบเต็ม (รองรับโฟลเดอร์ scripts + เต็มจอ):** เปิดผ่านเว็บเซิร์ฟเวอร์
- *วิธีที่แนะนำ:* อัปโหลดทั้งโฟลเดอร์ขึ้นเว็บโฮสต์ฟรี เช่น **GitHub Pages**, **Netlify**, **Cloudflare Pages** แล้วเปิดลิงก์ใน Safari
- *ทดสอบในเครื่อง Mac:* รันคำสั่งในโฟลเดอร์นี้
  ```bash
  python3 -m http.server 8000
  ```
  แล้วเปิด `http://[ไอพีของ Mac]:8000` บน iPad (ต้องอยู่ Wi-Fi เดียวกัน)

**ทำให้เต็มจอ + ไม่มีแถบ Safari:**
ใน Safari แตะปุ่มแชร์ → **“เพิ่มไปยังหน้าจอโฮม” (Add to Home Screen)**
แล้วเปิดจากไอคอนบนโฮม จะได้โหมดเต็มจอเหมือนแอปจริง 👍

## 🎛 ทิป

- เอียง iPad แนวนอน (landscape) จะอ่านได้สบายที่สุด
- เพิ่มความสว่างจอให้สุดเวลาถ่ายจริง
- ถ้าใช้กับกระจกสะท้อนหน้ากล้อง ให้เปิด **🪞 กระจก**
- ปรับความเร็วให้พอดีจังหวะพูด เริ่มที่ค่ากลาง ๆ แล้วค่อยจูน
